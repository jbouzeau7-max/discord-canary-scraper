# Avatar photo des webhooks

`webhook-avatar.jpg` est une version carrée de 512 × 512 px, recadrée pour rester lisible en avatar Discord. La photo source en pleine résolution est conservée dans `webhook-avatar-source.jpg`.

Source : [portrait Unsplash](https://unsplash.com/photos/man-with-beard-looking-up-with-arms-crossed-Eo5CDaYgVgo). La [licence Unsplash](https://unsplash.com/license) autorise l’utilisation gratuite, y compris commerciale, sans attribution obligatoire. L’attribution reste appréciée.

La photo est servie depuis une URL publique, car le dépôt du scraper est privé et Discord doit pouvoir charger l’avatar sans authentification. La même photo est utilisée pour les différentes identités `Datamining`, afin de donner une identité cohérente aux webhooks.
