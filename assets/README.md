# Icône stylisée des webhooks

`webhook-avatar.png` est l’avatar carré 512 × 512 destiné aux webhooks Discord. Il représente une fiole blanche stylisée sur un médaillon bleu et violet, dans l’esprit de la référence fournie par l’utilisateur. C’est une illustration, pas une photo de personne.

L’image est hébergée sur une URL publique, car Discord doit pouvoir charger l’avatar même si le dépôt du scraper est privé. Les identités de notification partagent cette icône pour conserver une marque cohérente.
