# Discord Canary Scraper

Automated scraper and notifier for Discord Canary client updates, experiments, rollouts, news, quests, shop, and more.

## Features

- Scrapes Discord Canary builds and chunks
- Tracks experiment rollouts and user rollouts
- Monitors news, quests, shop, mobile versions
- Webhook notifications with rich embeds
- GitHub Actions workflows for scheduled scraping
- Documentation site in `docs/`

## Setup

```bash
npm ci
```

See workflows in `.github/workflows/` for scheduled jobs.
